# Feature Status

## Planned
- AI media analysis and smart cutout
- motion tracking and object removal
- advanced color grading, masks and 360-degree workflows
- generative AI creation tooling
- Android and iOS native builds
- multi-platform export presets and social-media packaging

## In Progress
- timeline editing primitives and clip transforms
- project persistence format and migration strategy
- export pipeline + FFmpeg validation
- mobile capability registry and adaptive UI

## Implemented
- dark workspace shell
- project creation, save and open flow
- import media flow
- preview monitor
- multitrack timeline
- trimming and splitting logic
- transform controls (position, scale, rotation, opacity)
- one transition (cross-dissolve)
- audio volume control
- monochrome colour effect
- undo and redo flow
- regression tests for project logic

## Tested
- project creation
- split logic
- trim logic
- transform updates
- export descriptor generation

## Known Limitations
- no advanced GPU renderer yet
- no actual AI transcription or generative outputs
- no real mobile package build yet
- no complex multi-track editing gestures
- project schema is still a simple JSON form intended for first-phase compatibility
