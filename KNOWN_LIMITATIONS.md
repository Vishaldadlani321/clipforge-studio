# Known Limitations

1. This starter repository is intentionally limited to the first working milestone and does not yet include the full product scope described in the brief.
2. The preview is a functional workspace shell, not a full video renderer with GPU accelerated compositing.
3. Export currently relies on the FFmpeg CLI path for a generated MP4 output and is not yet a full project renderer with multi-clip effects composition.
4. There is no real AI provider integration, no transcription, and no cloud model workflow yet.
5. Mobile packaging and platform render capability checks are not yet implemented.
6. The project format is a simple file-based state model, not yet a production-safe native project schema with migration tooling.
7. Complex timeline operations like ripple edits, slip edits, multi-select, keyframes, masks and advanced audio tools remain future work.
